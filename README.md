## 📌 Overview

A fully responsive personal portfolio showcasing my skills, experience, and projects as a final-year B.Tech CSE student. Built entirely from scratch — no frameworks, no libraries, no build tools. Just clean, hand-written HTML, CSS, and vanilla JavaScript.

> **Deployed at:** [https://prachi-bagasi.netlify.app/] (Prachi_Bagasi_portfolio)
---

## ✨ Features

| Feature | Description |
|---|---|
| 🌸 Sakura Pink Theme | Custom light theme with warm tones and rose accents |
| 📱 Fully Responsive | Works seamlessly on mobile, tablet, and desktop |
| 🎞️ Scroll Animations | Sections animate in smoothly as you scroll |
| 💬 Skill Bubbles | Hover over the photo to reveal skill tags |
| 📂 Experience Accordion | Click to expand job details; others close automatically |

1. Clone the repository

```bash
git clone https://github.com/Prachibagasi/portfolio.git
```
2. Open index.html in your browser

No additional dependencies or setup required.


## 🎨 Theming

The entire colour palette lives in one place — the `:root` block at the top of `style.css`. Swap these 8 values to change the whole site theme:

```css
:root {
  --bg:      #fdf6f8;   /* page background    */
  --surface: #fff0f4;   /* section surfaces   */
  --border:  #f0c8d4;   /* borders            */
  --accent:  #d4527a;   /* primary accent     */
  --accent2: #9b6bb5;   /* secondary accent   */
  --text:    #2d1a22;   /* body text          */
  --muted:   #8a5a6a;   /* muted/helper text  */
  --card:    #fff7f9;   /* card backgrounds   */
}
```
